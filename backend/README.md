# Backend

Pasta reservada ao backend do Esqueceram AI e à sua publicação em um serviço Docker gratuito.

## Uso

O `Dockerfile` define a base de publicação e expõe a porta `10000`, conforme exigido pelo Render. A API, suas dependências e seus endpoints serão adicionados em issues específicas.

As variáveis de ambiente de produção devem ser configuradas no serviço de publicação, nunca versionadas no repositório.
